# Global project workflow

- Always inspect and use `SKILL.md` located in the current project directory before starting work.
- If the current project directory does not contain `SKILL.md`, create it before proceeding.
- Continuously update the applicable `SKILL.md` with newly learned or discovered project-specific information, decisions, constraints, and reliable procedures.
- Keep the file concise, accurate, and focused on reusable project guidance; do not store secrets.

## Automatic post-task update

- After completing each task, review the work for reusable knowledge that should be preserved in the applicable `SKILL.md`.
- Update `SKILL.md` before reporting completion when the task produced a new procedure, important decision, project constraint, troubleshooting result, dependency requirement, or implementation convention.
- Do not update the file for temporary details, one-off values, redundant information, or secrets.
- Record updates as short, actionable instructions or facts, including relevant scope and conditions where needed.
- Preserve existing guidance unless the task proves it incorrect; revise outdated entries instead of adding contradictions.
- After updating the file, verify that it exists and remains valid Markdown before finishing the task.
